# v1.1 Preview Coverage & Flow Reliability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the first v1.1 preview-only coverage slice for archives, SQLite databases, and more text/data formats while preserving the existing lightweight preview flow.

**Architecture:** Reuse the existing `FileRenderType -> ContentView` dispatch path. Add two render types, small focused data loaders, and simple SwiftUI preview views; avoid a new runtime layer or deep editor behavior.

**Tech Stack:** Swift, SwiftUI, Foundation `Process`, XCTest, existing QuickCookies preview state and file classification code.

---

## File Structure

- Modify `QuickCookies/Core/FileTypeClassifier.swift`: classify archive and database files before binary fallback.
- Modify `QuickCookies/Config/Constants.swift`: expand known text/data extensions and adjust blacklist for preview-only types.
- Create `QuickCookies/Core/ArchivePreviewLoader.swift`: list supported archive contents through system tools and parse output into lightweight entries.
- Create `QuickCookies/Core/SQLitePreviewLoader.swift`: read SQLite table/schema/sample summaries through system `sqlite3`.
- Create `QuickCookies/UI/StructuredPreviewView.swift`: shared preview-only UI for archive/database summaries.
- Modify `QuickCookies/UI/ContentView.swift`: route `.archive` and `.database` to `StructuredPreviewView`.
- Modify `QuickCookies/Core/Preview/PreviewSession.swift`: map new render types into the existing document/text runtime kind.
- Modify `QuickCookies.xcodeproj/project.pbxproj`: add the new Swift files to the app target.
- Modify `QuickCookiesTests/FileTypeClassifierTests.swift`: add focused tests for classification and loader parsing behavior.
